# BATTLEGROUNDS ARENA ⚽🏏

> Premier Sports Turf Slot Booking & Arena Management Suite.

Built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Vite**.

---

## 🌟 Highlights

### 1. 🏟️ Customer Booking Experience
- **Dual Court Architecture:**
  - **Pitch A ("The Colosseum"):** 7v7 Football / Box Cricket (120×70 ft, 50mm FIFA Astroturf)
  - **Pitch B ("The Thunder Cage"):** 5v5 Football / Pickleball (90×50 ft, Rebound Derby Cage)
- **Natural 3-Step Booking Flow:**
  - Step 1: Choose Pitch & Sport format
  - Step 2: 14-day date picker with weekday/weekend dynamic pricing
  - Step 3: Tactile time slots (06:00 AM – 01:00 AM) with peak floodlights indicator
- **Interactive 2D Field Diagram:** On-demand popup displaying goalposts, penalty boxes, 22-yard cricket pitch, and tactical formations.
- **Match Equipment Add-ons:** Match balls, bibs, referee, 4K match recording, hydration crates.
- **Flexible Checkout:**
  - Full Online Payment (100%)
  - 30% Token Advance (locks slot, balance paid at turf)
  - Pay at Turf (Cash on arrival)
  - Simulated UPI QR code
- **Digital Match Pass:** Scannable gate QR, unique `#BG-XXXX` booking reference, WhatsApp share button, and print stylesheet.
- **Community Battle Board:** Player matchmaking lobby for squads looking for teammates or open challenges.
- **Find My Pass:** Instant pass lookup by phone number or booking reference.

### 2. 📋 Turf Owner Management Hub
- **Executive Operations KPI Bar:** Today's matches scheduled, Gross value booked, Inflow realized in bank/cash, Counter receivables due at gate, Arena occupancy %.
- **Master Schedule Grid:** Interactive court timetable across pitches and operating hours with direct walk-in entry and slot hold/unblock.
- **Bookings CRM Ledger:** Filterable table (All, Today, Balance Due, Checked In), 1-click arrival check-in, 1-click counter balance collection, print manifest.
- **Slot Blocker:** Lock slots for maintenance, grooming, monsoon rain, or private tournaments.
- **Dynamic Pricing & Rules Engine:** Hourly rates per pitch, floodlight peak periods, emergency weather rain hold switch.
- **Revenue Analytics:** Revenue breakdown by sport, channel distribution (Online vs Walk-in vs Phone).
- **Gate QR Scanner Simulation:** Turnstile camera viewfinder with animated laser sweep and test pass verification (`#BG-9105`).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/ketanaryan/truf-.git

# Navigate into the folder
cd truf-

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
